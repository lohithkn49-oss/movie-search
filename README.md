# 🎬 Movie Search

Movie Search is a Python-based web application that allows users to search for movies and view detailed information about them.

## 🚀 Features

- 🔍 Search for movies by name
- 🎬 Display movie details
- ⭐ View movie ratings
- 📅 View release dates
- 🎭 View movie genres
- 📝 Read movie descriptions and overviews
- 🖼️ Display movie posters
- 🌐 Fetch movie information using a movie API
- 💻 Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Movie API

## 📌 Project Purpose

This project was developed to practice Python web development, API integration, and building a user-friendly web application.
